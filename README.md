# 返佣结算

本地桌面 CSV 统计工具。所有处理在本机完成，不上传数据、不连接交易所、不执行付款。

## 启动

macOS 推荐直接双击项目文件夹里的 **`返佣结算.app`**，直接打开界面，不会弹出终端。可以将 App 拖入程序坞方便下次启动，或在 Finder 中制作替身放到桌面。

这是当前项目的一键启动 App，使用现有 `.venv` 环境，每次启动都会加载最新代码；请保持 App 与 `app.py`、`.venv` 位于同一个项目文件夹，不要单独移走 App。它不是可脱离项目分发的独立安装包。启动异常会弹窗提示，错误日志在 `artifacts/launcher.log`。

App 始终运行所在项目的代码，不会把项目或 CSV 自动复制到其他目录。若 macOS 提示文件夹访问受限，请授权访问，或手动将整个项目文件夹移至可访问的位置。

也可以双击原有 `启动返佣结算.command`（会打开终端）。需要重新安装运行环境时，在项目目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Windows 安装依赖后用 `.venv\Scripts\python app.py` 启动（尚未在 Windows 验证）。

### 更新后检查环境

Git 更新代码不会同步更新 `.venv`。每次更新后，在项目目录执行以下步骤（安装依赖需要联网，日常运行不需要）：

```sh
git pull --ff-only origin main
.venv/bin/python -m pip install -r requirements.txt
./启动返佣结算.command --check
```

看到“返佣结算启动环境正常”后再双击 App。`--check` 不打开窗口；缺失环境或依赖时会显示错误及修复命令。依赖版本固定为已验证版本，当前验证环境是 Python 3.11 / macOS。

Excel 依赖缺失时，界面、统计和 CSV 导出仍可使用；选择 XLSX 导出会提示安装依赖，不会让整个程序无法启动。

## 使用

1. 点击选择文件（可多选）或把多个 CSV 同时拖入导入区。拆分文件须一起选中，合并为一个批次。当前样本选择默认 UTF-8；旧版中文 CSV 可显式选择 GB18030/GBK。下次启动会自动重新导入上次成功选择的文件；选择新文件会替换它们，文件选择器也会从上次目录打开。文件被移动或删除时会提示重新选择。
2. 在开始/结束日期框直接键入 8 位年月日数字，例如 `20260920`，界面自动补成 `2026-09-20`；可只填一端，留空表示不限日期。日期包含首尾全天，按原 CSV 日期，不转换时区。若结束日期晚于所选 CSV 的最新返佣日期，界面会提示后续日期暂无记录，便于核对导出范围。
3. 粘贴好友 ID（换行、空格、中英文逗号均可）。留空表示所有好友。ID 精确匹配，保留前导零；重复输入 ID 只匹配一次。
4. 点击“统计返佣”。支持全部/指定订单类型。修改日期、UID 或订单条件时，上次结果会保留并标记为待更新；复制和导出暂不可用，点击“统计返佣”后才替换结果。“清空条件”也需再次点击统计。
5. 查看 UID 核对、按日期、日期×好友三种汇总。UID 核对会逐个显示完整 UID、文件中是否存在、全批次笔数、匹配笔数、金额和状态；缺失及当前无记录的 UID 也保留为独立行。
6. 点击上方 UID 状态数字即可筛选下方 UID 表，再点同一项恢复全部；有未找到的 UID 时，红色区域内的状态数字也可点击。原有状态下拉框、查找和“复制表内 UID”仍可使用。这些操作仅改变表格显示，不改变上方的结算总额。导出当前表时可选择 CSV 或 Excel (`.xlsx`)；导出的是该表当前状态/查找范围内的行，因此筛选了状态的导出金额可能不同于主总额。XLSX 会把 UID 和精确金额保存为文本，避免 Excel 的科学计数法和 15 位数值精度限制。
7. “查看文件与全量核对”展示每份来源的记录数、完整金额和日期范围，便于检查分拆文件是否全部选入。

### UID 状态

- **所选文件无此 UID**：所有导入文件均未找到该 UID；不代表平台账号不存在，也不能从返佣文件推断此人是否为好友。
- **存在 · 当前条件无记录**：文件中能找到，但当前日期/订单条件下无记录。
- **有记录 · 净额为 0**：有匹配记录，但金额为 0（可能原始金额为零，也可能正负抵消），不能当成“从未交易”。
- **有返佣 · 净额为正**、**有记录 · 净额为负**：有匹配记录，按原始金额精确累计，不丢弃负数。

“无记录 / 净额为 0”筛选合并第二、三类；第一类和负数可单独筛选。留空 UID 时，核对表列出批次全部 UID，包括本期无记录者。输入 UID 时，核对表始终保留每个不同的输入 UID，不截断或隐藏在悬浮提示里。

输入的 ID 在所选文件中未找到时，会单独显示红色区域，列明数量和完整名单（长名单可滚动）。可直接复制名单，或点击“表内查看”后导出；这些 ID 在核对表中的整行也为红色。存在但当前无返佣的 ID 不列入缺失名单。名单随当前统计更新，不自动保存历史记录。

## 固定统计口径

- 使用 `好友ID（现货）`、`返佣时间`、`返佣收入(USDT)`。不使用注册时间或原始资产的“返佣收入”。表头兼容全半角括号、空格和大小写。已知订单类型会受控归一化：`Spot/SPOT/spot` 统一为 `spot`，`USDT-Futures/usdt-futures` 等大小写变体统一为 `USDT-futures`；未知订单类型保留原值，不擅自合并。
- **CSV 中每一行都是一笔返佣；完全相同的重复行也必须全部累加。没有记录去重功能。**
- 一次可统计多个 CSV。每次选择/拖入建立新的完整批次，替换此前所有文件；重新拖入不会叠加旧缓存。
- **不同文件中相同的行仍全部累计。** 同一个物理文件被重复选中（包括软/硬链接）会明确报错；不会按文件内容去重，不会删除任何原始记录。
- 金额使用 Decimal 精确运算，不逐笔舍入。显示及导出至少 8 位小数，更高精度最多保留 18 位。
- 界面金额汇总 CSV 的 `返佣收入(USDT)`；币安后台的“返佣总额 (USD)”采用美元估值，两个数值不能直接视为同一统计口径。
- 金额支持正数、负数、零及平台导出的科学计数法（如 `0E-8`、`1E-8`），直接用 Decimal 精确解析，不经过浮点数。展开后最多 30 位整数和 18 位小数；不接受 NaN、Infinity 或带千位逗号的金额。
- 任一文件缺列、非法 ID/金额/日期、行列数异常或导入中源文件变化时整个批次失败，提示文件名和行号（可定位时），不生成不完整结果。取消导入不发布部分结果。
- 支持 `YYYY-MM-DD`、`YYYY-MM-DD HH:MM:SS`（可含微秒；日期分隔符可为 `/`）。不接受带时区的时间，避免隐式转换。
- 本机只记住上次成功导入的文件路径、编码和选择目录，不保存原始数据、好友名单或历史结果；下次启动会重新读取源 CSV。读取后用日期×ID×订单类型汇总缓存，并建立 UID 到汇总桶的二级索引；指定少量 UID 时无需扫描全量 Bucket。
- CSV 和 XLSX 导出均包含来源文件、日期、ID、订单筛选条件及 UID 状态。较长的完整来源文件名和筛选 UID 列表仅在首条数据行写一次，其余行留空，避免导出体积平方膨胀；空结果导出只有表头。所有源 CSV（包括导入后改名、软/硬链接）禁止覆盖；源文件移动后仍可导出缓存结果。
- CSV 保留完整 ID 字符串，但 Excel 直接打开 CSV 仍可能自动转成科学计数法；需要直接双击交付给 Excel 用户时优先导出 XLSX。XLSX 中 UID 与 `返佣收入(USDT)` 是精确文本，返佣笔数和全批次笔数仍为数值。XLSX 单表最多 1,048,576 行（含表头）、单元格最多 32,767 字符；超限或含 Excel 不支持的字符时明确报错，建议缩小筛选范围或导出 CSV，不静默截断内容。导出失败保留原有目标文件，并清理临时文件。

## 验证

推送 `main` 或提交 Pull Request 后，GitHub Actions 会在全新的 macOS / Python 3.11 环境中安装运行依赖、检查两个启动入口，再安装测试依赖并运行完整回归测试。更新和发布须确认检查通过；具体维护要求见 `AGENTS.md`。

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
```

真实数据验收（只读运行成品统计核心，不打印明细）：

```sh
.venv/bin/python tools/verify_sample.py 0831-返佣.csv
```

多文件全量独立核验（整数定点逐行求和，对比生产 Decimal 缓存的每个分组；同时核对 40 组筛选、UID 状态、文件前后 SHA-256）：

```sh
.venv/bin/python tools/verify_batch.py part1.csv part2.csv --report outputs/batch-verification.json
```

也可通过命令行启动并导入多份文件：`.venv/bin/python app.py part1.csv part2.csv`。
重复打开桌面 App 时只会激活已有窗口；若新启动命令带有 CSV 文件，会在已有窗口导入该批文件。

程序不包含自动打款、返佣比例拆分或已付款状态管理。
